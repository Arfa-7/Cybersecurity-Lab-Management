## Project Description
This program is made for cybersecurity lab ki inventory and to calculate total investment cost.

## Input
- Lab name
- Number of computers, network devices, security tools
- Cost per computer, cost per network device
- Annual security software cost

## Processing
Computer Cost = Number of Computers × Cost per Computer
Network Cost = Number of Network Devices × Cost per Device
Total Lab Investment = Computer Cost + Network Cost + Software Cost
